# KrattOS docs

The full project is split by audience. Start here.

## If you want to grow food
- [`operator-manual/getting-started.md`](operator-manual/getting-started.md): unbox a KrattOS, set it up, run your first crop.

## If you want to build one (DIY)
- [`hardware/krattos-lite.md`](hardware/krattos-lite.md): the budget tiers (Lite, ~$279 as a kit; Nano, ~$149). You bring a room, a wire rack, and trays. The kit ships the brain.
- [`hardware/bom.md`](hardware/bom.md): the full appliance hardware spec.

## If you want to back the project
- [`business/gofundme-copy.md`](business/gofundme-copy.md): the live $3,000 proof campaign.
- [`business/gofundme-story-plaintext.md`](business/gofundme-story-plaintext.md): paste-ready version for the GoFundMe editor.

## If you want to contribute code
- [`developer/architecture.md`](developer/architecture.md): how the system is built. Two compute tiers, NATS bus, recipe engine, control loops, safety supervisor.
- [`developer/contributing.md`](developer/contributing.md): dev setup, test conventions, how to add a service.

## If you're making something with the brand
- [`../assets/brand/README.md`](../assets/brand/README.md): wordmark, mark, palette, type, do/don'ts. The SVGs have the font embedded.

## If you're planning the long game (post-proof)
The docs in `business/` other than the GoFundMe copy describe the
**post-proof** plan: what to do once the first unit grows food on
camera and the project goes for a real seed round. They are not what
the live campaign is asking for.

- [`business/fundraising-roadmap.md`](business/fundraising-roadmap.md)
- [`business/pitch-deck-outline.md`](business/pitch-deck-outline.md)
- [`business/unit-economics.md`](business/unit-economics.md)
- [`business/bom.md`](business/bom.md) (full appliance, $2,900 in parts)
- [`business/bom-lite.md`](business/bom-lite.md) (Lite ~$195, Nano ~$112)
